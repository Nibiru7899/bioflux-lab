Target: frontend/src/App.tsx. Mode: Operate. Code-led redesign; no approved raster UI comp.

The user requested a substantial visual improvement with motion, imagery and better graphs, explicitly delegated taste with "Use your judgment and proceed", then asked to use a framework other than Streamlit. ## Direction contract
THESIS: A clear working laboratory makes predicted and solver-verified outcomes distinct while bringing the model's topology into view.
OWN-WORLD: Molecular atlas / structural biology journal illustration. Light sage working surfaces, deep navy topology canvas, Manrope typography, seafoam reaction squares, blue metabolite circles, amber succinate and coral disabled reactions. Standard app navigation, native inputs, aligned tables and separate work regions.
STORY: Set nutrient capacities and up to two gene deletions. Inspect the affected graph, predict, verify, compare and calculate the growth–production range. Inspect recorded core and genome experiments in Research results.
FIRST VIEWPORT: Top navigation, parameter rail, compact scenario summary, dark interactive model beside the outcome/actions. The graph remains topology, never an invented flux animation. The self-hosted conceptual cell image supports biological context in the rail.
SIGNATURE: Hover or keyboard-select a real graph node to reveal its immediate connections; select the succinate neighborhood to focus the same actual network. Predictions and solver answers arrive with a short state transition and explicit source labels.
MOTION: CSS press/hover feedback, 240ms Motion opacity/translate result transitions, 180ms graph connection emphasis, chart reveal; useReducedMotion and CSS reduced-motion handling. No decorative perpetual motion; only loading rotates.
FINISH: Fresh skill finish reviewer with desktop/mobile screenshots; final design documenter writes token-bearing DESIGN.md and .impeccable/design.json. Shipping raster has exact embedded generation prompt and sidecar, and self-hosted font has source/hash/license.

## Direction decision

Seed 098208f5 ran; the grounded list considered botanical plates, crystallographic figures, field guides, conference graphics, research identity systems, molecular structural atlases (candidate 6), and ecological maps. Candidate 6 carries the mechanism through graph identity, not tool costumes. The marketing monochrome challenger was declined for weak biological identification; its clarity discipline raises source-label consistency. The orienteering challenger was declined as a literal map costume; its legend discipline raises persistent categorical graph labels. The user-pinned layout and existing scientific constraints govern this working screen.
